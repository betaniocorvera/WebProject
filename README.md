# WebProject
Online Conference Registration System — a 2nd Year Final Project designed to provide a simple and organized way for participants to register for conferences and for administrators to manage and monitor registration records online.

Features

Online conference registration

Participant information management

Registration record viewing and management

Admin dashboard

Search and filtering of registered participants

Digital attendance/check-in records

CRUD operations for registration data

Project Purpose

This project aims to replace traditional paper-based conference registration and logbook processes with a web-based system that makes participant registration and record management more organized, accessible, and efficient.
